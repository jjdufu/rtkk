# 发版改为 Debian 13 x86_64，版本从 0.0.0 起

## 背景

上一版工作流按四个平台打包，并在 Ubuntu 26.04 上编 Linux 二进制。本项目只在 Debian 13 的 Linux x86_64 上测试过，Ubuntu 26.04 的 glibc 比 Debian 13 新，编出来的二进制在 Debian 13 上跑不了。版本也不该从 0.1.0 起。

## 代码

发布和 CI 都先 `docker pull debian:13`，再在这个镜像里编译。只打 `linux_amd64` 包。`install.sh` 拒绝其它系统。

`Cargo.toml`、`Cargo.lock` 里的 rtkk 版本和 `.release-please-manifest.json` 改为 `0.0.0`。Release Please 配置写了 `initial-version: 0.0.0`。1.0 前 feat/fix 仍涨 patch，下一版是 `0.0.1`。

## 数据库

无。

## 配置

打包镜像不钉 digest，每次发布拉取最新 `debian:13`。宿主机 runner 仍是 `ubuntu-26.04`，只负责拉镜像和上传产物，不参与链接。

## 验证

```bash
bash -n .github/scripts/release/debian13-build.sh
bash -n .github/scripts/install/install.sh
python3 .github/scripts/release/sync-workspace-lock-version.py
```

`sync-workspace-lock-version.py` 输出 `updated Cargo.lock package version to 0.0.0`。没有在本机跑 GitHub Actions。

## 部署说明

本地 `.git` 按要求删掉后重新提交并推到已重置的 `main`。到 pulls 点两次 Approve and run workflows，绿了再 Merge pull request。
